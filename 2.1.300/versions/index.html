    Versions¶

    Every view of this site is built from the same recordings. A version's view marks each gotcha as recorded or not recorded on that version; nothing is claimed for a version that no recording covers. A dot means no recording on that version shows it, which is not the same as fixed.

    How a new version gets here¶

    A nightly job records a set of scenarios with the newest released CLI and decodes them with the same code that decodes the committed recordings. When the CLI changes shape, the run goes red, the new recording is committed as a fixture, and the next build of this site gains that version's view, with the change on it.
