**Goal:** The seven polish slices the owner's Mac test of PR #3 asked for: running groups that open and mark the live call, a `Show more` / `Show less` toggle that resets on collapse, the desktop's composer box with a `+` button and a footer of plain-text mode and model · effort controls plus a context ring, coloured Bash bodies with a `Bash` header, the inline code pill, a hover action row (Copy, Fork from here, relative time) under each reply, and image attachments (paste, drop, `+` menu) sent as base64 blocks and shown as thumbnails live and on reload.

## Global Constraints

- CLAUDE.md hard rules, verbatim, each with what it means here:
  1. **Never block the EDT.** No process I/O, file I/O, JSON parsing or waiting on the CLI from the UI thread. Use the platform coroutine scopes (`platform-coroutines-structured-concurrency` skill).
     - Here: base64 encoding in `ComposerSender` on `Dispatchers.Default`; clipboard contents and files read on `Dispatchers.IO` (only the clipboard's flavour list is queried on the EDT); thumbnails decoded in the presenter's child coroutines on `Dispatchers.Default`; `ShellTokens.tokenize` runs where the body is built (the builder, off the EDT), never in composition; the file chooser is modal and stays on the EDT.
  2. **No Node, no Agent SDK at runtime.** We spawn the user's `claude` binary directly. Do not add a sidecar.
  3. **Never touch credentials.** Auth belongs to the CLI. Do not read `~/.claude/.credentials*`, keychains or API keys, and never offer a login flow. (The recording tasks use the sandbox's own sign-in through `scripts/record-scenario.sh`.)
  4. **Edits go through the IDE, not the disk.** Unchanged: no edit path is touched.
  5. **Never fail silently.** If the CLI falls back to another model, rejects a model, retries, or errors, the user sees it in the chat. Compare the model in the `system/init` event (and fallback events) with what the user picked.
     - Here: the model control shows the running model (`init.model` by `resolvedModel`), never the picked one after an `init` disagreed; an `apply_flag_settings` error restores the effort with `Effort not changed: <error>`; a refused image gets its notice; a prompt dropped at close gets `This prompt was not sent before the session closed`; a fork with no transcript gets `This session has no transcript to fork yet`.
  6. **Every protocol change gets a fixture test.** Recorded transcripts live in `src/test/resources/fixtures/`. Unknown message types must parse to `Unknown(raw)`, never throw.
     - Here: `effort-switch`, `permission-mode-auto` (P3) and `user-image` (P6), each with its `transcripts/` twin, recorded with `scripts/record-scenario.sh` and redacted with `scripts/redact_fixture.py`; `synthetic-long-reply.ndjson` stays the only unrecorded fixture.
  7. **Do not bundle kotlinx.coroutines or the Kotlin stdlib.** The platform provides both.
  8. **Do not call the product "Claude Code"**, in the plugin name, ID or UI. Use "Tandem" and say it works with Claude Code. Never in a `chat/` or `ui/` string here (`Claude handles permission decisions` is fine); P7 greps.

## Review Focus

1. A tool call whose input is still streaming (`PENDING`, `block.input == null`) and then completes while its row is open must gain its body on the complete line without a second click, never show a body built from partial JSON → P1 `a call's body appears once its input completes`.
2. A digit pressed in the mode menu while that mode is hidden (`1` with `Auto` unsupported) or beyond the model list must pick nothing, never the entry at that position → P3 `a digit of a hidden mode picks nothing`.
3. A `result` whose `modelUsage` does not list the active model (a mid-turn fallback) must still give the ring a window (the largest listed), never hide it or throw → P4 `the window falls back to the largest listed when the active model is not in modelUsage`.
4. A reply stamped later than the host's clock (a transcript from another machine, clock skew) must read `just now`, never `-3 minutes ago` → P5 `a time in the future reads just now`.
5. A clipboard whose flavours cannot be read (`IllegalStateException: cannot open system clipboard`, common on Linux and macOS while another app holds it) must leave Cmd/Ctrl+V to the text area, never swallow the key or throw → P7 `a clipboard that cannot be read is a text paste`.
6. An image file deleted or unreadable between the chooser and the read must leave the notice `<name> could not be read`, never an exception or a silent skip → P7 `a file that cannot be read leaves a notice, not an exception`.
